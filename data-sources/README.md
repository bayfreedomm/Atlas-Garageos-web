# Source data for src/data/generated/cars.json

Not shipped with the site. Regenerate with:

    python3 scripts/build-cars-data.py data-sources/epa-vehicles.csv data-sources/ankusi-fitment.xlsx

- `epa-vehicles.csv` — U.S. EPA / DOE fuel economy data, https://www.fueleconomy.gov/feg/download.shtml (vehicles.csv; public domain U.S. government data).
- `ankusi-fitment.xlsx` — ANKUSI Wheel Fitment Dataset v2026.10.04 (CC BY 4.0), https://github.com/david025445/ankusi-wheel-fitment-data — attribution is shown on every page that uses it.
