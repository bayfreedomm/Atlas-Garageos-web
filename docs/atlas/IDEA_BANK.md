## Evaluation gate for every idea

Before acceptance, record: user problem, search/product value, unique data, source permission, evidence quality, reusability, technical dependency, privacy/safety risk, duplication risk, route/internal-link design, and an MVP boundary. “Many pages” or “AI can write it” is not sufficient evidence.
